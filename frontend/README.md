# 🎨 Frontend - Sistema de Controle de Estoques

## Configuração

### Pré-requisitos
- Node.js 18+
- npm ou yarn

### Instalação

```bash
cd frontend
npm install
cp .env.example .env
```

### Variáveis de Ambiente
Edite `.env` com URL da API.

### Iniciando

```bash
# Desenvolvimento
npm run dev

# Build para produção
npm run build
```

## Páginas

- **Dashboard**: Visão geral de estoque e custos
- **Inventory**: Gestão de itens
- **Occupancy**: Registro de hóspedes
- **Forecasting**: Previsões de consumo
- **Consumption**: Registro de consumo/desperdício
- **Analytics**: Análise de custos e desperdício
- **Reports**: Relatórios gerenciais

## Tecnologias

- React 18 com Vite
- Tailwind CSS
- Recharts (gráficos)
- React Router
- Axios
